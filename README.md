# PCGN_EDMC_Plugin
Plugin required for the Elite Dashboard app.


Install ED Market Connector (EDMC),
-- Download and Instruction can be read here: https://github.com/EDCD/EDMarketConnector/wiki/Installation-&-Setup

Once EDMC Is working. Install the PCGN Plugin. (Download the plugin below.),
-- In EDMC Click on File --> Settings and click on the Plugins tab.
-- Click on Open Plugins Folder. This will open up file explorer and this is the place were you add the PCGN plugin your downloaded from the Discord.
-- Unzip the PCGN Plugin file and place the load.py file there. The file path should be \EDMarketConnector\plugins\PCGN\load.py
-- Restart EDMC and you should now see the PCGN tab in the EDMC settings.

Login to elite.pcgn.net website, and go to your My Profile.,
-- In the EDMC Plugin Setup section create your API token in you haven't already.
-- Next copy this API key and paste in the PCGN Plugin in EDMC. Click on the PCGN Tab and paste your API key and click Save.

If all done correctly, keep EDMC running while you play Elite Dangerous and you'll see the Elite Dashboard start populating your actions from the game
